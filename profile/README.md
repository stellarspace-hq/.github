# StellarSpace

A next-generation NFT-based space shooter on Stellar

Collect NFT ships with real attributes, then take them into real-time space combat.

## Why StellarSpace

- NFT ships — each ship is a unique collectible with Attack, Speed, and Shield attributes
- Real-time shooter — gameplay layered on top of on-chain ownership
- Scaffold Stellar Registry — contracts managed and deployed through the registry
